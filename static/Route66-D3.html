Route 66 · D3｜Carthage → Oklahoma City 分段导航链接

2026年11月23日（周一）· CST

使用方法

  • 从第 0 段开始。每到一站、停好车之后，再打开下一段链接。
  • 所有链接都开了「避开收费」（!2b1）。第 1 段另外开了「避开高速」（!1b1）。
  • 手机 App 打开链接时，路线选项不一定都会保留。开始导航前，到「路线选项」里确认一下勾选的项目。
  • Buck Atom 之后二选一： 时间和日照都充足，就走 A 线（7A → 7B）。如果 12:45–13:00 以后才离开 Buck Atom，或者预计赶不上 16:00–16:45 到酒店，就走第 8 段。OKC 日落约 17:19。

参数速查（data 字段）

设置 data 串
仅避开收费 /data=!4m4!4m3!2m1!2b1!3e0
避开收费 + 避开高速 /data=!4m5!4m4!2m2!1b1!2b1!3e0

!1b1 表示避开高速，!2b1 表示避开收费，!3b1 表示避开轮渡，!3e0 表示驾车。!Nm 后面的数字是它后面子字段的个数，所以每多加一个选项，外面几层的计数都要一起加 1。
